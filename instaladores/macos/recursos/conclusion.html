EspañolCode está instalado

Abre la Terminal (en Aplicaciones > Utilidades) y prueba:

espanolcode --ayuda
espanolcode /usr/local/share/espanolcode/ejemplos/hola.esp

Para desinstalarlo, escribe en la Terminal:

sudo rm /usr/local/bin/espanolcode
sudo rm -rf /usr/local/share/espanolcode
sudo pkgutil --forget io.github.0xkgjavi.espanolcode
